НЕФРИТОВЫЙ ПУТЬ — PSP (проверочная сборка)

Это первый smoke-test нативного PSP-порта, а не финальная игра.
Его задача — проверить, что GitHub Actions и pspdev собирают рабочий
EBOOT.PBP для PSP.

Что должно быть на экране после запуска:
- тёмно-зелёный фон;
- поле 7×7 из цветных квадратов;
- золотая рамка-курсор.

Управление в этой проверке:
- D-pad — двигать курсор;
- Start — выход.

Установка:
1. Скопируй папку JadePath на карту памяти:
   ms0:/PSP/GAME/JadePath/
2. Внутри должен лежать EBOOT.PBP:
   ms0:/PSP/GAME/JadePath/EBOOT.PBP
3. Запусти игру из меню PSP → Game → Memory Stick.

Требуется CFW (6.60/6.61 PRO/LME/ARK). Homebrew не подписывается.

Если экран чёрный или сборка не запускается — пришли лог GitHub Actions,
будем исправлять. После успешной проверки начнётся перенос самой игры:
100 уровней, бонусы, лёд, жизни, музыка и сохранения.
